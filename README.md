# ApnaFood Partner - Step 1

This is a Flutter starter for the first working prototype.

Included:
- Partner Login screen
- Mobile/password validation
- OTP button placeholder
- Forgot password placeholder
- Restaurant registration placeholder
- Partner Dashboard
- Today's orders/earnings cards
- Quick action cards
- Bottom navigation

## Run

1. Install Flutter.
2. Create/open this project folder in Android Studio or VS Code.
3. Run:
   flutter pub get
   flutter run

This version uses demo/local navigation only. Real OTP, database, restaurant registration,
orders, payments, notifications, and backend APIs will be added in later steps.
